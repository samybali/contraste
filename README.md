# Projet Artishow Contraste - Clustering Incrémental

## Description générale

Ce projet implémente des algorithmes de clustering incrémental basés sur le principe de **Minimum Description Length (MDL)** pour des données en 1D et 2D. L'approche utilise des représentations binaires et des structures arborescentes hiérarchiques pour organiser les données sans nécessiter de distance métrique traditionnelle.
